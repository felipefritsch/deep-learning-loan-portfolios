# Research artifacts

This directory contains the final dissertation and compact result artifacts that support the public
codebase. Large binary files are stored with Git LFS rather than as ordinary Git blobs.

- `1101489_dissertation.pdf` — submitted Oxford MSc dissertation.
- `results/m14_pools/` — retained pool-level fixture used by a reproducible figure script.
- `results/m27a_results*/` — compact rolling sequence-model metrics.
- `results/m27b_mc/` — matched sequence-pricing summaries and Parquet outputs.

The raw Fannie Mae dataset, trained model weights, caches, and full output lake are not distributed.
Third-party papers, university guidance, meeting notes, and private working documents have been
removed from the public repository. Their copyright and licensing remain with their owners.
