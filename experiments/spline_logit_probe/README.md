# Spline-logit probe — k2015 go/no-go (THROWAWAY; not a model member)

Run: `PYTHONPATH=src .venv/bin/python experiments/spline_logit_probe/run_probe.py`. Full numbers in `results.json`; figure in `shapes.png`.

- **Raw gap (primary):** additive splines (per-feature cubic B-splines, **no interactions**) cut k2015 test NLL from plain-logit **0.10813 → 0.10669**, a raw gap of **0.00144** — about **31%** of the 0.00465 logit→GBT gap. That fraction is orientation-only and **knot-sensitive**: 24% / 31% / 49% at knots 5 / 8 / 12 (doubly approximate — 1.5M subsample, and a geo-dropped probe measured against a geo-inclusive GBT denominator).
- **The gain is all `current`-origin:** +0.00165 there (98% of test rows), while on the sparse delinquent origins the extra basis overfits and slightly **hurts** out-of-sample (dpd_30 −0.0008, dpd_60 −0.0031, dpd_90+ −0.0156) — the reverse of the "interactions live in current" prior; additive shape is what `current` was missing.
- **Shapes recovered** (2015 test-slice PDP vs empirical equal-population-bin hazard, origin=current): incentive **S-curve**, loan-age **seasoning hump**, current-LTV **hump**, FICO **up-for-prepay / convex-down-for-dpd_30** — the additive model tracks the Ch.3 hazard shapes; the main miss is the high-incentive prepay tail (empirical saturates, PDP keeps climbing — a burnout/interaction effect).
- **Validity:** the plain probe reproduces the deployed logit to **|Δ|=1.1e-4** (0.10813 vs 0.10825) despite dropping MSA+Zip3 — geography adds ~nothing over the macro features + Property State; the 1.5M subsample matches full-train base rates to **0.0017** (the train→test drift of 0.31 is why the check is anchored to train, not test).
- **Read:** additive nonlinearity closes a meaningful-but-minority (~quarter-to-half) slice of the gap, concentrated in current-loan prepay/early-delinquency **shape**; the delinquent-origin residual looks interaction-driven. The natural follow-up — if any — is a spline **+ interaction** member, not additive-only.
